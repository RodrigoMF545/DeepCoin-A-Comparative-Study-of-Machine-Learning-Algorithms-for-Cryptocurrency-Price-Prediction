# DeepCoin-Estudo-Comparativo-de-Algoritmos-de-Machine-Learning-na-Previs-o-de-Criptomoedas
Este repositório contém o desenvolvimento de uma interface gráfica para análise, avaliação e inferência de modelos de previsão de preços de criptomoedas, construída sobre artefactos previamente treinados e armazenados.
